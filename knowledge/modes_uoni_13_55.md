# Режимы РД, электроды УОНИ-13/55 (v1)

> ⚠ **Черновик агента, требует проверки инженера.** Таблицы сведены агентом из
> типовой практики РД; до первого прогона агента (критерий приёмки issue #4)
> каждую таблицу подтверждает инженер. Значения, в которых агент не уверен,
> помечены `⚠` на месте.

Файл заполняет `params` операции для процесса РД электродами УОНИ-13/55,
материалы ст3 и 09Г2С, толщины 3–16 мм.

## Род тока и полярность

| Параметр | Значение v1 | Поле контракта |
| -------- | ----------- | -------------- |
| Род тока | `постоянный` | `current_type` |
| Полярность | `обратная` (электрод «плюс», изделие «минус») | `polarity` |

УОНИ-13/55 — электроды с основным покрытием: сварка на постоянном токе
обратной полярности. Переменный ток структурно допустим контрактом
(`current_type: "переменный"`, без `polarity`), но для УОНИ-13/55 в v1 **не
применяется**: он требует повышенного напряжения холостого хода источника и
ухудшает стабильность дуги ⚠ (инженер подтверждает формулировку).

## Диаметр электрода и сварочный ток (нижнее положение)

| Диаметр электрода, мм | Сварочный ток, А (нижнее положение) | Поле контракта |
| --------------------- | ----------------------------------- | -------------- |
| 3 | 70–90 | `electrode_diameter_mm` = 3, `current_a` из диапазона |
| 4 | 100–130 | `electrode_diameter_mm` = 4, `current_a` из диапазона |
| 5 | 130–160 | `electrode_diameter_mm` = 5, `current_a` из диапазона |

Правила выбора значения из диапазона:

1. Начинать с середины диапазона; верхняя граница — для сплошных швов большого
   сечения в нижнем положении.
2. В вертикальном и потолочном положениях ток снижается на ~10–20 % ⚠ от
   тока для нижнего положения; в горизонтальном — берётся ближе к нижней
   границе ⚠.
3. Первый (корневой) проход многослойного шва — по нижней границе диапазона
   для выбранного диаметра ⚠; `current_a` в контракте один на операцию, поэтому
   берётся значение для основного (заполняющего) прохода, а сомнение
   выносится в `assumptions[]`.

## Толщина → диаметр и число проходов (стыковые швы, нижнее положение)

| Толщина, мм | Диаметр, мм | Число проходов | Примечание |
| ----------- | ----------- | -------------- | ---------- |
| 3–4 | 3–4 | 1 | Кромки без скоса |
| 5–6 | 4 | 1–2 ⚠ | Скос кромок не обязателен; второй проход при требовании полного провара ⚠ |
| 7–8 | 4 | 2 | V-образный скос ⚠ (разделка задаётся чертежом, картой не описывается) |
| 9–12 | 4 | 3 | V-образный скос ⚠ |
| 13–16 | 4–5 | 4–5 | V- или X-образный скос ⚠ |

## Угловые швы: катет → диаметр и число проходов

| Катет шва, мм | Диаметр, мм | Число проходов |
| ------------- | ----------- | -------------- |
| 3–4 | 3–4 | 1 ⚠ (см. «Расхождение с эталоном») |
| 5–6 | 4 | 1 |
| 7–8 | 4–5 | 1–2 ⚠ |
| 9–10 | 5 | 2–3 ⚠ |

**Расхождение с эталоном, вынесенное на решение инженера:** эталон
[`examples/minimal/ok.json`](../examples/minimal/ok.json) задаёт
`pass_count: 2` для угловых швов катетом 4 мм, тогда как типовая практика —
один проход. Эталон не правится файлом знаний; при первом прогоне агент
следует этому файлу и выносит расхождение в `assumptions[]` — инженер
закрепляет одну из практик.

## Материал: ст3 и 09Г2С

| Параметр | ст3 | 09Г2С |
| -------- | --- | ----- |
| Режимы (ток, диаметр, проходы) | по таблицам выше | те же, что для ст3 той же толщины |
| Технологические отличия | нет | узел допустимых скоростей охлаждения шире; многослойные швы вести короткими участками ⚠ |
| Подогрев | не требуется (3–16 мм, положительные температуры) ⚠ | при отрицательных температурах — подогрев до 100–120 °C для толщин от ~10 мм ⚠; граница подтверждается инженером |

Подогрев — вне полей контракта: при необходимости он фиксируется в
`assumptions[]`, а не в `params`.

## Связь с контрактом

Заполняемые поля операции: `position` (из расположения-базы брифа), `params`
(`current_type`, `polarity`, `current_a`, `electrode_diameter_mm`,
`pass_count`). Реалистичность режимов по этим таблицам позже проверяет
линтер (см. [`linter/README.md`](../linter/README.md), «Not in scope yet»).
