# Режимная таблица УОНИ-13/55 (РД, v1)

Назначение: единственный источник режимов (`params`) для контракта
[`ok.json`](../contract/README.md). Область v1: РД, ст3/09Г2С, толщины
3–16 мм, электрод УОНИ-13/55 (тип покрытия — основной, тип Э46А).

> **Статус: черновик агента.** Таблицу токов и проходов до первого прогона
> обязан подтвердить инженер (задача #4). Значения с `⚠` — неуверенные,
> выбраны по типовой практике, а не по конкретному справочнику.

## Род тока и полярность

| Параметр | Значение |
| -------- | -------- |
| Род тока | `постоянный` |
| Полярность | `обратная` (электрод «+») |

Обоснование: электроды с основным покрытием (УОНИ-13/55) работают на
постоянном токе обратной полярности. Прямая полярность и переменный ток для
v1 **не применяются**: валидатор допускает их структурно, но файл знаний таких
режимов не выдаёт.

## Режимы по толщинам

Нижнее положение, стыковые и угловые швы; катет углового шва ≈ толщине
детали. Значения — типовая практика для УОНИ-13/55.

| Толщина, мм | Диаметр электрода, мм | Ток, А | Число проходов | Примечание |
| ----------- | --------------------- | ------ | -------------- | ---------- |
| 3 | 3 | 70–90 | 1 | Без разделки, односторонний шов. |
| 4–5 | 4 | 100–130 | 1–2 | Без разделки; 1 проход для угловых швов малого катета. |
| 6–8 | 4 | 100–130 | 2 | Со скосом кромок при стыковом шве. |
| 9–12 | 4 | 100–130 | 3 | Со скосом кромок. |
| 13–16 | 4 | 100–130 | 4–5 | Со скосом кромок; при многопроходной сварке в нижнем положении для заполняющих проходов допускается Ø5, ток 130–160 А ⚠. |

Проверка на примере: [`../examples/minimal/ok.json`](../examples/minimal/ok.json)
— s = 4 мм, Ø4, 130 А, 2 прохода — внутри диапазонов таблицы.

### Поправки на положение сварки

| Положение | Ток относительно нижнего |
| --------- | ------------------------ |
| Вертикальное (снизу вверх) | −10…−15 % |
| Потолочное | −10…−20 %; электрод Ø5 не применять |
| Горизонтальное на вертикальной плоскости | −10…−15 % ⚠ |

## ст3 против 09Г2С

Значения токов, диаметров и проходов **одинаковы** для обеих марок в диапазоне
v1: УОНИ-13/55 даёт равнопрочное соединение и с той, и с другой сталью.
Различия — в технологии:

- 09Г2С: зачистка кромок до металлического блеска обязательна; вести короткой
  дугой, не допускать перегрева и поджогов.
- 09Г2С: подогрев для толщин до 16 мм при положительных температурах не
  требуется ⚠ (границу применения при отрицательных температурах определяет
  инженер при приёмке).

## Ограничения v1

- Одно значение `current_a` на операцию: из диапазона таблицы выбирается одно
  число (обычно середина диапазона ⚠); спорный выбор выносить в
  `assumptions[]`.
- Число проходов в таблице — для нижнего положения и катета ≈ s; при иной
  разделке число проходов корректирует инженер при приёмке (контракт v1
  разделку не хранит).
