# welding-ok

Генератор операционных карт (ОК) для сварных изделий: агент производит инженерное содержание (JSON-контракт), детерминированный рендерер оформляет его по ГОСТ 3.1118-82 / ГОСТ 3.1404-86.

## Language

### Документы

**ОК (операционная карта)**:
Технологический документ ЕСТД, описывающий сборочно-сварочную операцию; форма — ГОСТ 3.1118-82, содержание граф — ГОСТ 3.1404-86. Итоговый продукт системы.
_См. также_: Контракт

**Бриф**:
Полу-структурированный markdown-документ с фиксированными разделами (Детали, Расположение-база, Прихватки-приспособление, Швы, Ограничения), описывающий сварную конструкцию. Единственный вход агента.
_Avoid_: ТЗ, задание

**Контракт (ok.json)**:
Структурированное представление содержимого ОК без оформления. Выход агента, вход линтера и рендерера.
_Avoid_: модель, схема

**Синтетический эталон**:
Пара `brief.md` + `ok.json` на выдуманное реалистичное изделие, написанная вручную инженером. Ground truth для тестов агента и рендерера.

**Заглушка-ссылка на эскиз**:
Ссылка в ОК на номер эскиза карты эскизов (КЭ); сам эскиз выполняется вручную и в систему не входит.

### Конвейер

**Черновик**:
Результат агента до приёмки. Всегда полный, спорные решения вынесены в `assumptions[]`.

**Приёмка**:
Инженерная проверка черновика человеком. Единственный судья инженерной правоты; линтер проверяет только согласованность.

**Линтер**:
Детерминированная проверка согласованности бриф ↔ контракт: каждый шов покрыт операцией, номера операций монотонны, у каждой операции есть позиция/оборудование/режим.

**Рендерер**:
Детерминированный скрипт контракт → ok.xlsx (Python + openpyxl). Единственный владелец оформления; не принимает инженерных решений.

**Файлы знаний**:
Курируемые русскоязычные файлы: типовые переходы, режимные таблицы, правила последовательности сварки. Источник инженерных знаний агента.

### Сварка

**РД**:
Ручная дуговая сварка покрытыми электродами. Процесс v1.

**Шов (Ш1, Ш2, …)**:
Сварной шов, идентифицируемый номером с чертежа изделия. Совпадает с нумерацией чертежа и карты эскизов.
